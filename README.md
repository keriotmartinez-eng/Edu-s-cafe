
# Edu's Café - Página Web

## Descripción del proyecto

Edu's Café es un emprendimiento de repostería artesanal ubicado en León, Nicaragua, que ofrece pasteles personalizados, cupcakes, brigadeiros y otros postres.

Este proyecto consiste en desarrollar una página web donde los clientes puedan conocer los productos del negocio, ver fotografías, consultar precios y solicitar cotizaciones de pedidos personalizados.

Nuestro objetivo es facilitar el acceso a la información de los productos y mejorar la comunicación entre el negocio y sus clientes.

## Tecnologías utilizadas
- HTML5: estructura de la página web.
- CSS3: diseño y estilos visuales.
- JavaScript: funcionalidades interactivas.
- Git y GitHub: control de versiones y trabajo en equipo.
- Visual Studio Code: editor de código.
- Figma: diseño de interfaces y prototipos.

## Estructura del proyecto

- `index.html`: archivo principal de la página.
- `css/styles.css`: estilos de la página web.
- `js/main.js`: funciones de JavaScript.
- `img/productos/`: imágenes de los productos.
- `docs/`: documentación del proyecto.
- `.gitignore`: archivos que Git debe ignorar.

## Cómo ejecutar el proyecto

1. Clonar el repositorio desde GitHub.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html` en un navegador.
4. También se puede utilizar la extensión Live Server de VS Code.

## Organización del trabajo

Utilizaremos GitHub Projects para organizar las historias de usuario y dar seguimiento a las tareas pendientes, en progreso y terminadas.

### Convenciones de Git

- La rama `main` contendrá las versiones funcionales del proyecto.
- Cada historia de usuario se desarrollará en una rama independiente, por ejemplo: `feature/HU-01-catalogo`.
- Los commits se escribirán en español, en tiempo presente y con el código de la historia correspondiente.
- Los cambios se integrarán mediante pull requests revisados por otro integrante.
